# Roadmap

OSS Readiness Checker is intentionally small. The goal is to help new maintainers improve public repository quality without turning the tool into a full project management platform.

## Planned

- Detect GitHub Actions workflow names and common CI providers.
- Add a Markdown output mode for issue comments and release notes.
- Add fixtures for Python, Node.js, Rust, and documentation-only repositories.
- Improve scoring guidance for early projects with no external contributors yet.

## Not planned

- Automatic star, fork, or activity generation.
- Remote scanning without explicit user input.
- Ranking projects against each other.
- Making claims about eligibility for any specific grant or support program.
