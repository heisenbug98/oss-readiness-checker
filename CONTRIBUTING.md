# Contributing

Thanks for taking a look at OSS Readiness Checker.

## Local setup

```bash
git clone https://github.com/your-name/oss-readiness-checker.git
cd oss-readiness-checker
npm test
```

This project has no runtime dependencies. Node.js 18 or newer is enough.

## Good first contributions

- Add a new readiness check with clear advice.
- Improve the scoring weights.
- Add fixtures for common repository layouts.
- Improve README examples.
- Add documentation for first-time maintainers.

## Pull request checklist

- The change has a clear user-facing reason.
- `npm test` passes.
- New behavior is covered by a focused test.
- The README is updated when usage changes.
